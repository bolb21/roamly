# Third-party data and assets

Everything shipped in the app must come from public-domain or openly licensed data.
This file records each source, its licence, and which shipped files use it.

## Globe textures (`assets/globe/`)

Built by `npm run build:globe-textures` (`scripts/build-globe-textures.mjs`). Raw
downloads go in `data-raw/`, which is not committed.

| Shipped file | Made from | Licence |
| --- | --- | --- |
| `earth-4096.jpg`, `earth-2048.jpg`: red = shaded relief, blue = ocean depth | NOAA NCEI **ETOPO 2022** 60 arc-second global relief model, surface elevation (`ETOPO_2022_v1_60s_N90W180_surface.tif`). Relief shading and depth scaling computed by our script | CC0 1.0 public domain dedication (per the [data.gov record](https://catalog.data.gov/dataset/etopo-2022-15-arc-second-global-relief-model)). Suggested citation: NOAA National Centers for Environmental Information, 2022: ETOPO 2022 15 Arc-Second Global Relief Model. DOI: 10.25921/fd45-gt74 |
| `earth-*.jpg`: green = land mask; `countries-4096.png`, `countries-2048.png`; `country-ids.json` | **Natural Earth** 1:50m Admin 0 countries, via the `world-atlas` npm package (`countries-50m.json`); rasterised by our script | Natural Earth: public domain ([terms of use](https://www.naturalearthdata.com/about/terms-of-use/)). `world-atlas`: ISC licence |
| `clouds-2048.jpg` | Generated by our script from layered noise | Ours (no third-party data) |

Sources:
- ETOPO 2022: https://www.ncei.noaa.gov/products/etopo-global-relief-model
- Natural Earth: https://www.naturalearthdata.com/
- world-atlas: https://github.com/topojson/world-atlas

Style references in `docs/design/globe-ref-2.jpeg` and `globe-ref-3.jpeg` are used for
look and feel only. None of their imagery is copied, traced or shipped.
